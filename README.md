# JavaScript Course - SuperSimpleDev

## 🇺🇸 English

This repository contains my studies, exercises, and projects developed while completing the JavaScript course by **SuperSimpleDev**.

The goal of this repository is to document my learning process and practice the concepts introduced throughout the course.

### 📚 Topics studied

Throughout the course, I practiced concepts such as:

- JavaScript fundamentals
- Variables, functions, conditionals, and loops
- Arrays and objects
- DOM manipulation
- Event listeners
- Modules and imports/exports
- Local Storage
- Object-Oriented Programming (OOP)
- Automated testing with Jasmine
- Callbacks
- Promises
- `async` / `await`
- `fetch` and APIs
- HTTP requests (`GET` and `POST`)
- Error handling with `try` / `catch`
- Basic frontend and backend concepts

### 🛒 Main Project

One of the main projects developed throughout the course was an **Amazon-inspired e-commerce website**.

The project includes features such as:

- Product listing
- Shopping cart
- Checkout page
- Quantity updates
- Delivery options
- Order summary
- Payment summary
- Orders page
- Product tracking
- Local Storage
- Automated tests with Jasmine
- API requests using `fetch`

### 🧪 Testing

The project also includes automated tests created with **Jasmine** to practice testing JavaScript functions and application logic.
